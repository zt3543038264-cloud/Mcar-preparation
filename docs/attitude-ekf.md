# 姿态 EKF 移植说明

默认解算已从 Mahony 切换为四元数误差状态 EKF。入口、200 Hz 采样、IMU660RA 量程、菜单姿态变量及导航坐标保持兼容。上电静置约两秒完成标定；烧录后重新做 Navigation/Zero 再测试位置控制。

## 来源与取舍

阅读了相邻 `project/code/Attitude.c`、`QuaternionEKF.c/.h`、`kalman_filter.c/.h`、`matrix.c/.h` 和 `EKF_Platform.h`。参考实现为 Wang Hongxi 的 QuaternionEKF，采用四元数与 X/Y 陀螺零偏估计、加速度低通、创新卡方检测及自适应增益。

本次提取其融合思路，重新实现固定维度误差状态 EKF，没有直接复制整套通用矩阵库。名义状态为单位四元数和 X/Y 残余零偏；协方差对应三个小角度误差和两个零偏误差。与参考项目的“四元数四维 + 两个零偏”状态表达不同。Z 零偏继续由现有导航确认深度静止后缓慢跟踪。

参考代码的以下细节没有沿用：

- `Attitude.c` 输出 g，EKF 静稳判断却使用 9.8 附近的阈值；新实现统一使用 g。
- 固定 2 ms 更新周期改用当前实际采样 dt。
- 初始化的低通参数被写死，改为随 dt 计算低通系数。
- 小于 0.008 rad/s 的角速度清零会漏掉缓慢真实偏航，取消此死区。
- 将四元数 z 分量的校正置零不等于保持欧拉 Yaw 不变；新实现使用重力观测的局部误差模型。
- 参考项目的 Q/R 与 1e-8 卡方阈值不能直接用于新的误差状态和单位，重新定义噪声及归一化创新门限。

保留了当前项目的连续静止标定窗口、重力初始化、静止 Z 零偏跟踪、有限值/dt 检查、失败时不提交状态、超时及重新标定机制、Flash 擦写后采样恢复。使用精确轴角四元数增量、Joseph 协方差更新和误差注入后的协方差坐标重置，不依赖动态内存。

## 文件与参数

- `project/code/attitude.c`：`ekf6_init/update/euler/cube_euler`；原 Mahony/Madgwick 仍保留。
- `project/code/attitude.h`：`Ekf6` 状态与统一 `Ahrs6` 接口。
- `project/code/imu.c`：导航帧的 X/Y 角速度额外扣除 EKF 残余零偏；原始 Sensor 角速度不改变。
- `project/code/config.h`：`AHRS_METHOD_EKF=3`，默认启用。改为 1/2 可切回 Mahony/Madgwick，用于相同条件对比。

EKF 参数为编译期参数，不进入现有 Flash 配置：

| 参数 | 默认值 | 含义 |
|---|---:|---|
| `EKF_GYRO_NOISE` | 0.0001 | 角度误差过程噪声密度 |
| `EKF_BIAS_NOISE` | 1e-8 | X/Y 残余零偏随机游走密度 |
| `EKF_ACCEL_VARIANCE` | 0.0025 | 单位重力方向观测噪声方差 |
| `EKF_CHI_SQUARE_LIMIT` | 11.345 | 三维归一化创新平方门限 |
| `EKF_ACCEL_LPF_TAU_S` | 0.01 s | 加速度低通时间常数 |
| `EKF_BIAS_LIMIT_RADPS` | 0.08726646 | X/Y 残余零偏限幅，约 5°/s |

先用默认值。加速度抖动明显时可增大观测方差，让滤波更相信陀螺；低通时间常数越大，运动时重力观测滞后越明显。加速度模长不在原有 0.85–1.15 g 范围内，或创新异常时，仅进行陀螺预测。模长与创新门限不能识别所有持续线性加速度。

## 验证与上板检查

`tests/attitude_ekf_test.c` 覆盖长期静止、变 dt、慢速/多圈偏航、倾斜初始化、X/Y 零偏收敛、三轴复合转动、异常加速度、NaN/dt 拒绝与重置。`imu_navigation_publish_test.c` 用模拟 SPI/时钟检查三种算法的导航发布、标定、超时和异常间隔行为。

主机仿真不能验证实际噪声参数和板上执行耗时。上板先架空电机检查：静置角度、左转 Yaw 增大、手动转一圈的航向增量、横移时 Roll/Pitch 抖动和 5 ms 中断执行时间，再低速试跑。不要把轮速环或死区造成的启动偏航归因于姿态算法。

六轴姿态没有绝对航向观测。EKF 有助于估计倾斜与 X/Y 零偏、拒绝部分异常加速度，但不能保证消除长期 Yaw 漂移，也不能保证直接解决车子横移时的偏航。

## WiFi 诊断通道

2026-10-18 修正：原实现允许重力观测通过四元数修正改变 Euler Yaw，且在拒绝观测时冻结了加速度低通历史，恢复观测时历史方向没有跟随陀螺预测更新。回归输入为 30 秒、角速度为零、水平加速度为 0.12g 的旋转方向变化：原实现可产生约 -27.26° 的假航向，间歇拒绝观测时约 -88.36°。这证明实现存在假航向通道，但不能证明某次实车误差全部由它造成。

现在低通历史每帧随陀螺增量传递到当前机体系，包括拒绝观测的帧；角度卡尔曼增益投影为零 Euler Yaw 修正，Joseph 协方差更新使用投影后的增益；有限四元数倾斜修正后保持该帧陀螺预测的 Yaw。新仿真上述两种假漂移均小于 0.03°，加入真实 Z 轴转动后航向仍能跟踪。保留慢速角速度输入、倾斜估计与 X/Y 残余零偏估计。六轴长期漂移与运动加速度对倾斜的影响依然存在，不能视为绝对航向保证。

以下名称已接入现有 `SUB` / `LIST?`，只读，不进入 Flash：

| 名称 | 单位及含义 |
|---|---|
| `imu_dt_ms` | 两次成功读取六轴数据的入口时间间隔，ms；第一帧只建立基准，下一帧起更新。异常大 dt 也会记录，结合 `imu_status` 判断 |
| `imu_solve_us` | 最近一次成功姿态更新从滤波调用到欧拉角计算的耗时，μs；不含 SPI 读取。若被中断抢占则包含等待时间 |
| `imu_solve_max_us` | 上述耗时峰值，IMU 初始化或重新标定时清零 |
| `imu_accel_used` | 最近一次成功更新：1=融合加速度，0=拒绝；尚未完成更新时为 -1 |
| `ekf_nis` | 归一化创新平方；大于 `EKF_CHI_SQUARE_LIMIT` 拒绝融合。未计算（如模长提前拒绝）、初始化或非 EKF 时为 -1 |
| `ekf_bias_x_dps` / `ekf_bias_y_dps` | EKF 在上电标定基础上估计的 X/Y **残余**零偏，°/s；非总零偏。非 EKF 时为 0 |
| `imu_seq` | 成功发布的姿态帧序号；标定完成发布第一帧为 1。重新标定清零，超时/无新数据不增加 |
| `imu_method` | 1=Mahony，2=Madgwick，3=EKF |
| `accel_norm_g` | 当前读取的原始加速度模长，g |
| `gyro_z_integral_deg` | 独立积分扣除标定/静止跟踪零偏后的传感器 Z 角速度，度；初始化/重新标定清零，Navigation/Zero 不清零。用于比较行驶前后增量，不是完整三维 Euler Yaw，明显倾斜时两者可以不同 |

耗时、融合标志与 EKF 诊断仅在成功更新后刷新；传感器无新数据、故障时可能保留旧值，应同时检查 `imu_status` 和 `imu_seq`。上位机记录会对板上帧抽样，单帧标志的统计比例不能直接视为全体板上帧的精确比例。

`tests/imu_diagnostics_telemetry_test.c` 验证诊断订阅值、NIS 无效标记、32 通道列表及 LIST 响应长度。
