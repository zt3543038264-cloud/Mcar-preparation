# Route 节点编辑与掉电保存

`Route/Nodes` 固定每次加减 1，范围为 1～8。全局步长只影响坐标等其他参数，长按继续逐个加减。

保存步骤：

1. 在 `Route` 中设置 `Nodes` 和各节点的 `X_cm/Y_cm/Yaw`。
2. 将 `Route/SaveCfg` 置为 On；根目录 `SaveCfg` 也可。
3. 保存动作会取消运行中的路线，并保存节点数、全部 8 个节点，以及原有 PID、位置环和导航参数。
4. 上电自动恢复已保存配置，路线保持停止。静止完成 Navigation/Zero 后，将 `Route/Run` 置为 On 才开始行驶。

编辑节点本身只改 RAM，不会每按一次键就擦写 Flash。修改后需要再次执行 SaveCfg。

Flash 格式升级为 v2，使用原来的扇区和页，共 53 个 32 位字。带版本和校验信息，非法节点数量、非有限数和越界坐标不接受。

兼容原 v1：原来的 PID、位置环和导航参数仍可加载；没有路线字段时使用默认 3 点路线。下次 SaveCfg 会写成 v2。未知版本或校验失败时不应用存档，保留启动默认值。

主机测试使用内存模拟 Flash，覆盖掉电恢复流程、8 个节点、旧格式兼容、损坏数据、擦写失败和停止状态；实际板上擦写和重启仍需烧录验证。
